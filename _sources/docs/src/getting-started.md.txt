# Getting started

Start with [Select a worker and inspect its configuration](tutorial.md). It provides a complete exercise using one YAML file and a Python script.

For an existing Airflow deployment, the [how-to guides](examples.md) cover Python configuration, Hydra composition, SSH hooks, pool reconciliation, and the viewer. Consult the [reference](API.md) for fields and method behavior, and the [explanation](explanation.md) for how selection and scheduling interact.
