# airflow-balancer

Select configured hosts and ports for Airflow tasks, generate SSH hooks, and inspect configuration in a viewer. Core models come from `airflow-pydantic`; YAML composition comes from `airflow-config`.

[![Build Status](https://github.com/airflow-laminar/airflow-balancer/actions/workflows/build.yaml/badge.svg?branch=main&event=push)](https://github.com/airflow-laminar/airflow-balancer/actions/workflows/build.yaml)
[![codecov](https://codecov.io/gh/airflow-laminar/airflow-balancer/branch/main/graph/badge.svg)](https://codecov.io/gh/airflow-laminar/airflow-balancer)
[![License](https://img.shields.io/github/license/airflow-laminar/airflow-balancer)](https://github.com/airflow-laminar/airflow-balancer)
[![PyPI](https://img.shields.io/pypi/v/airflow-balancer.svg)](https://pypi.python.org/pypi/airflow-balancer)

Python 3.11 or later is required. Install the package for configuration loading, or choose the extra for your Airflow version:

```bash
pip install airflow-balancer
pip install 'airflow-balancer[airflow]'   # Airflow 2
pip install 'airflow-balancer[airflow3]'  # Airflow 3
```

For conda-forge:

```bash
conda install -c conda-forge airflow-balancer
```

- [Tutorial: select a worker and inspect its configuration](docs/src/tutorial.md)
- [How-to guides: Python, YAML, SSH, pools, and the viewer](docs/src/examples.md)
- [Reference: models, queries, loading, and viewer settings](docs/src/API.md)
- [Explanation: selection, pool limits, and port availability](docs/src/explanation.md)

Selection chooses randomly among matching configured hosts. `free_port()` excludes ports listed in configuration. The [explanation](docs/src/explanation.md) describes how these choices relate to Airflow scheduling and resource ownership.
